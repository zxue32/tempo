# 三家店试点手册

这份手册是现场用的。网站能算的东西，网站已经替你算了，比如漏斗、真实时长、对账单、每晚自检。下面这些事只能人去店里做。

**目标**：每家店都用真实数据证明三件事。

1. 网站给出的可约时间是对的；
2. 客人不用人教，能自己约成；
3. 店里愿意用它代替纸本和电话。

---

## 时间安排（每家店大约 6 周）

| 阶段 | 时间 | 做什么 | 在网站哪里 |
|---|---|---|---|
| 0. 摸底 | 上线前 1–2 周 | 收素材、访谈、记基线数字 | “试点数据 → 上线前的数字” |
| 1. 设置 | 上线前 2–3 天 | 按访谈结果设置服务、员工、排班、规则；用纸本试算检验 | “店里的规则”“服务项目”“试点数据 → 纸本试算” |
| 2. 客人测试 | 上线前 | 5 位真实客人试约，改完再测，至少 3 轮 | 用手机打开店铺链接 |
| 3. 双轨试运行 | 上线后头 2 周 | 纸本照用，每天关门对账 | “试点数据 → 打印今天的对账单” |
| 4. 停用纸本 | 连续 14 天零差异后 | 店主同意后停用 | — |
| 5. 对比 | 上线 4 周后 | 和基线比，决定是否推广 | “试点数据 → 上线前 vs 最近 30 天” |

三家店不要同一周上线。先上一家，跑顺一周再上第二家，这样第一家发现的问题不会在三家同时出现。

---

## 0. 摸底：每家店要拿到的原始素材

- [ ] 过去 4–8 周的预约记录原件：纸本拍照、Google 日历截图、微信 / IG / 短信预约聊天记录
- [ ] 收银系统（Square、Clover 等）带时间戳的流水导出
- [ ] 店铺平面图：工位、足浴椅、水槽、烘干位、UV 灯各几个
- [ ] 排班表、轮牌表原件；技师请假和午饭习惯
- [ ] 前台连续 5 个营业日的来电记录：预约、改约、取消、未接各几个
- [ ] 墙上价目表拍照，再问实际怎么收费（加价、优惠）
- [ ] Google 商家后台的数据（电话、导航、网站点击），以及差评里提到“等太久”“约不上”的内容
- [ ] 当地法规：员工提成是否满足最低工资；给客人发自动短信要先拿到同意（以后加短信时用）

### 基线数字（填进“试点数据 → 上线前的数字”）

| 数字 | 怎么数 |
|---|---|
| 爽约率 | 翻纸本 2–4 周：没来的 ÷（来了的 + 没来的） |
| 线上预约占比 | 通过私信 / 网页约的 ÷ 全部预约 |
| 每天预约电话 | 前台连续 5 天画“正”字：预约、改约、取消都算 |
| 技师每天空闲小时 | 所有技师在班但没有客人的小时数加起来，抽 3 天平均 |

上线后电话要接着数一周，填进“现在每天预约电话”。网站看不到电话。

## 0. 访谈问题（店主、前台各 20 分钟，技师每人 10 分钟）

问的时候请对方讲最近一次的真实情况，比如“上周六是怎么排的”，不要只问“一般怎么做”。

**设备 →“店里的规则 → 设备”**

1. 有几张足浴椅、几个水槽、几个烘干位？有没有因为设备不够、人有空也做不了的时候？
2. 哪些服务需要占用这些设备？

**散客 →“给散客留位”**

3. 进门不预约的客人大概占多少？哪几天、哪几个时段最多？
4. 散客来了没人接，你们会怎么办？想留几个人给散客？

**分配 →“任意技师怎么分”**

5. 散客现在怎么分给技师：轮牌，还是谁有空给谁？
6. 客人点名要某位技师，这一次算不算她的一轮？
7. 技师有没有抱怨过分配不公平？

**时长 →“服务项目”和“员工 → 自己的时长”**

8. 每项服务，每位技师大概要多久？新手和熟手差多少？
9. 换客人要清台多久？（填进“店铺设置 → 每个预约后的整理时间”）
10. 客人手上有旧甲时多久能卸完？客人自己知道要选卸甲吗？（可以设成“预约时问客人”）

**不占手时间（先记下来，这一版还不支持）**

11. 有没有客人泡脚、晾干的时候，技师先去照顾另一位客人？多常见？

**爽约 →“爽约限制”**

12. 爽约的客人现在怎么处理？爽约几次就不让在线约比较合适？

**语言**

13. 技师平时用什么语言？中文、英文、越南语，还是别的？（如果需要越南语，告诉我们）

把答案按上面的箭头填进网站，再用下一节的“纸本试算”检验一遍。

---

## 1. 纸本试算（用历史检验设置）

1. 打开“试点数据 → 纸本试算”，下载表格模板。
2. 把过去 2–4 周纸本上的预约录进去，一行一个预约：日期、开始、结束（不知道可以空着）、技师、项目（多个项目用 + 连起来）。
3. 点“开始试算”。
   - **全部排得进去**：设置和现实一致。
   - **有排不进去的**：按“原因”改设置，比如时长太长、排班不对、设备数量太少、技能没勾，然后再试，直到全部排进去。
   - **“实际用时和设置差 15 分钟以上”**：把这项服务的时长改成实际用时。

---

## 2. 客人测试（每轮 5 人，至少 3 轮）

**找谁**：老客 2 位、新客 1 位、年长的 1 位、英语或中文不是母语的 1 位。用他们自己的手机，不要用店里的平板。

**怎么做**：把店铺链接发给对方，只说下面这句话，然后不提示、不帮忙，只观察。

> “请帮我约一个下周六下午、Mia 做的 Gel 美甲，手上现在有旧甲。”

**记录（每人一行）**

| 客人 | 成功了吗 | 用时（秒） | 卡在哪一步、说了什么 | SUS 分数 |
|---|---|---|---|---|
| 1 | | | | |
| 2 | | | | |
| 3 | | | | |
| 4 | | | | |
| 5 | | | | |

**SUS 问卷（约完立刻填，1 = 非常不同意，5 = 非常同意）**

1. 我愿意经常用这个网站预约。
2. 我觉得这个网站没必要地复杂。
3. 我觉得这个网站很容易用。
4. 我需要别人帮忙才能用这个网站。
5. 我觉得网站的各项功能衔接得很好。
6. 我觉得网站里有太多前后不一致的地方。
7. 我想大多数人很快就能学会用它。
8. 我觉得用起来很别扭。
9. 用的时候我很有信心。
10. 用之前我需要先学很多东西。

**算分**：单数题得分 −1，双数题 5 − 得分，10 题加起来 × 2.5，满分 100。

**通过标准**：

- 至少 90% 的客人能在 90 秒内自己约成；
- SUS 平均 80 分以上。

没达到就把“卡在哪一步”整理给我，改完再测下一轮。

---

## 3. 双轨试运行（上线后头 2 周）

1. 纸本照常用，网站也同时用。所有预约两边都要有：电话约的、散客，前台都要在网站上录一遍。
2. 每天关门后，打开“试点数据 → 打印今天的对账单”，拿纸本逐条对：时间、技师、客人、项目。
   - 纸本上有、对账单上没有的，写在空行里；
   - 时间、技师或项目对不上的，写在“备注”栏。
3. 把差异数和原因填进“试点数据 → 双轨试运行”。
4. 连续 14 天零差异后，店主同意，就停用纸本。

**每天顺便看一眼**

- 技师有没有在“我的日程”里点“开始服务”和“完成”？做满 5 次以后，“真实服务时长”会给出建议时长，点一下就能改。
- “自动检查”有没有报错？报错就截图发给我。

---

## 4. 什么时候算成功、什么时候停

**可以推广到下一家**：

- 双轨期间连续 14 天零差异；
- 4 周内自动检查零错误；
- 爽约率不高于上线前；
- 线上预约占比上升，或每天预约电话下降；
- 店主愿意停用纸本。

**要停下来**：

- 出现任何一次重复预约，或设备超数量（自动检查会报错）；
- 一周内有 2 位以上客人反映“网上能约，到店却没人做”。

停下来以后先回到纸本，把问题发给我，查清楚再继续。
